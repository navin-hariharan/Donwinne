# Snoopy sample files

Used by `../snoopy.test.ts`.

## Real Snoopy files (redistributed under LGPL-2.1)

`fig2_single-reaction.hpn`, `fig3_sir.cpn`, `fig4a_syn-reaction.hpn`, `fig4b_deg-reaction.hpn`,
`fig5a_reverible-reaction1.hpn`, `fig6_feedbackLoops.cpn`, `fig7a_diffusion1d.hpn`, `fig8_caSpine.hpn`
and `fig10_cellcycleExample.hpn` are unmodified copies from

- Source: https://github.com/Herajy/design-patterns-in-computational-biology (branch `main`),
  fetched through https://raw.githubusercontent.com/Herajy/design-patterns-in-computational-biology/main/
- Licence: GNU Lesser General Public License v2.1; the full text is in `LICENSE-design-patterns`
  (copied from the repository's `LICENSE`).

They were written by Snoopy (revisions 1.22 and 2.0) and cover Continuous and Hybrid Petri Nets,
logical places, Comment metadata, observers, coloured arcs and Modifier edges.

## Hand-written files

`handwritten-mutex.spped` is written by hand in the layout of real Snoopy "Petri Net" files
(revision 1.21). The real files it was modelled on (e.g. `ma1.spped` from a Brunel University
course page) carry no licence and are not redistributed here.
